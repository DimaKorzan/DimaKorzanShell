DimaKorzanShell

Полноэкранная оболочка-«режим фокуса» для Windows 10/11: рабочий стол с иконками, меню Пуск, своя панель задач, медиа-плеер с синхронизированными текстами песен и статус в Discord.

Один файл main.cpp: чистый WinAPI и Direct2D, без внешних библиотек.

⚠️ Проект экспериментальный. Он скрывает панель задач и рабочий стол Windows и ставит глобальный хук на клавиатуру. Перед запуском прочитай DISCLAIMER.md и раздел «Если что-то пошло не так».

Возможности
Рабочий стол и Пуск на весь экран: иконки, поиск приложений, цветовые темы, прозрачность, обои или анимированный фон.
Своя панель задач. Резервирует место внизу экрана, поэтому развёрнутые окна не заезжают на неё. В полноэкранном режиме (F11 в браузере, видео, игры) окно закрывает панель само.
Запуск нескольких приложений сразу. Выбери приложение в Пуске (Ctrl+клик), дальше обычные клики добавляют в выбор. Запуск: кнопка «Запустить выбранные» или Enter в поиске.
Медиа-панель слева внизу: обложка, название, управление, текст песни. Данные берутся из системного плеера Windows (браузер, Spotify и т. д.).
Синхронизированные тексты. Тайминги с LRCLIB, обложка и запасной текст из Genius (по желанию). Если тайминга нет, текст показывается без подсветки с пометкой «без тайминга».
Discord Rich Presence через локальный IPC.
Защита от падений: при сбое возвращается стандартная оболочка Windows, а приложение один раз перезапускается.
Установка
Готовый файл

Скачай .exe из раздела Releases и запусти. Файл config.json появится рядом с ним при первом запуске.

Сборка из исходников

Нужны Windows 10 (1809+) или 11, Visual Studio 2022 (MSVC) и Windows SDK 10.0.17763+ (для C++/WinRT). В «x64 Native Tools Command Prompt»:

bat
cl /std:c++20 /permissive- /utf-8 /O2 /EHsc /DUNICODE main.cpp /link /SUBSYSTEM:WINDOWS
Управление
Действие	Как
Аварийный выход	Ctrl+Alt+Q
Вернуться в оболочку	Ctrl+Alt+Space, язычок у правого края экрана или кнопка Win
Пуск	Win / Win+D / Win+Q
Настройки Windows	Win+I
Проводник	Win+E
Скриншот области	Win+Shift+S
Выбрать несколько приложений	Ctrl+клик по плитке в Пуске
Настройки (config.json)
Поле	Описание
theme, opacity, iconScale, animBg, wallpaper	Внешний вид
hideTaskbar	true — своя панель, панель Windows скрыта. false — панель Windows остаётся
killExplorer	Закрывать Проводник при запуске. Не рекомендуется
geniusToken	Токен Genius API (необязательно)

Большинство настроек меняется прямо в программе: Пуск → Настройки.

Genius (необязательно)

Без токена тексты с таймингами работают через LRCLIB. Чтобы дополнительно получать обложки и запасной текст с Genius:

Создай клиент на https://genius.com/api-clients и скопируй Client Access Token.
Впиши его в config.json: "geniusToken": "твой_токен".

Не публикуй свой config.json и токен.

Discord

Application ID задан константой kDiscordAppId в main.cpp. Чтобы статус отображался под твоим названием и иконкой, создай приложение на https://discord.com/developers/applications и подставь его ID.

Советы
Для первого запуска лучше взять виртуальную машину или отдельную учётную запись Windows.
Оставь killExplorer выключенным.
Запомни Ctrl+Alt+Q и команду /restore.
Не добавляй программу в автозагрузку, пока не убедился, что она стабильно работает.
Не запускай её на чужом или рабочем компьютере без разрешения владельца.
Если что-то пошло не так

Панель задач или рабочий стол не вернулись:

bat
DimaKorzanShell.exe /restore

Либо нажми Ctrl+Alt+Q, либо открой Диспетчер задач (Ctrl+Shift+Esc) → «Запустить новую задачу» → explorer.exe.

Известные ограничения
Позиция трека берётся из системного плеера Windows. Некоторые браузеры обновляют её редко, поэтому текст может чуть опаздывать или спешить.
Тайминги есть не у каждой песни: если их нет на LRCLIB, их не будет.
Антивирусы могут ругаться из-за глобального хука клавиатуры и скрытия окон системы. Исходный код открыт, его можно проверить и собрать самостоятельно.
Работа на нескольких мониторах протестирована слабо.
