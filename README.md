DimaKorzanShell

Полноэкранная оболочка-«режим фокуса» для Windows 10/11: рабочий стол с иконками, меню Пуск, своя панель задач, медиа-плеер с синхронизированными текстами песен и статус в Discord. Один файл main.cpp, чистый WinAPI + Direct2D, без внешних библиотек.

⚠️ Проект экспериментальный. Он скрывает панель задач и рабочий стол Windows и ставит хук на клавиатуру. Прочитай раздел «Дисклеймер» до запуска.

Возможности
Рабочий стол и Пуск на весь экран: иконки, поиск приложений, темы, прозрачность, обои или анимированный фон.
Своя панель задач. Резервирует место внизу экрана, поэтому развёрнутые окна не заезжают на неё. В полноэкранном режиме (F11 в браузере, видео, игры) окно закрывает панель само.
Запуск нескольких приложений сразу. Выбери приложение в Пуске (Ctrl+клик), дальше обычные клики добавляют в выбор. Запуск: кнопка «Запустить выбранные» или Enter в поиске.
Медиа-панель (слева внизу): обложка, название, управление, текст песни. Данные берутся из системного плеера Windows (браузер, Spotify и т. д.).
Синхронизированные тексты. Тайминги с LRCLIB, обложка и запасной текст из Genius. Если тайминга нет, текст показывается без подсветки с пометкой «без тайминга».
Discord Rich Presence через локальный IPC (без библиотек).
Защита от падений: при сбое возвращается стандартная оболочка Windows и приложение один раз перезапускается.
Требования
Windows 10 (1809+) или Windows 11
Visual Studio 2022 (MSVC) и Windows SDK 10.0.17763+ (нужен C++/WinRT)
Сборка

В «x64 Native Tools Command Prompt»:

bat
cl /std:c++20 /permissive- /utf-8 /O2 /EHsc /DUNICODE main.cpp /link /SUBSYSTEM:WINDOWS

Получится main.exe. Файл config.json создаётся рядом с exe при первом запуске.

Аварийное восстановление, если что-то пошло не так, например панель Windows не вернулась:

bat
main.exe /restore
Настройки (config.json)
Поле	Описание
theme, opacity, iconScale, animBg, wallpaper	Внешний вид
hideTaskbar	true — своя панель, панель Windows скрыта. false — панель Windows остаётся
killExplorer	Закрывать Проводник при запуске. Не рекомендуется
geniusToken	Твой токен Genius API
Токен Genius

В коде и в релизном .exe токена нет. Без него обложки и запасной текст с Genius отключены, а тексты с таймингами с LRCLIB работают как обычно. Чтобы включить Genius, добавь свой токен в config.json.

Создай клиент на https://genius.com/api-clients, возьми Client Access Token и впиши в config.json в поле geniusToken.

Перед публикацией репозитория удали токен из исходника (константа kGeniusDefaultToken в main.cpp) и перевыпусти тот, что уже где-то светился. Всё, что попало в публичный репозиторий, считается скомпрометированным, даже если ты потом удалил коммит.

Discord

Application ID задан константой kDiscordAppId. Создай своё приложение на https://discord.com/developers/applications и подставь его ID, если хочешь свои название и иконку в статусе.

Что лучше делать и чего не делать

Лучше:

Сначала запусти на второй учётной записи Windows или в виртуальной машине.
Оставь killExplorer выключенным.
Запомни Ctrl+Alt+Q и команду /restore.
Держи config.json вне git, если там твой токен.

Не стоит:

Не ставь программу в автозагрузку, пока не убедился, что стабильно работает.
Не используй на рабочем или чужом компьютере без разрешения владельца.
Не публикуй токены и ключи в коде, в issues и в скриншотах.
Не рассчитывай, что это замена Explorer для повседневной работы.
Известные ограничения
Позиция трека берётся из системного плеера Windows. Некоторые браузеры обновляют её редко, поэтому текст может чуть опаздывать или спешить.
Тайминги есть не у каждой песни. Их нет на LRCLIB — значит их не будет.
Антивирусы могут ругаться на программу из-за глобального хука клавиатуры (WH_KEYBOARD_LL) и скрытия окон системы. Это ложное срабатывание, но проверяй исходник сам.
Работа на нескольких мониторах протестирована слабо.
